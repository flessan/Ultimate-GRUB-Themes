# Contributing

[English](Contributing.md) | [Bahasa Indonesia](Contributing.id.md)

This is a community-maintained catalog. Contributions of original themes and well-made themes discovered online are welcome.

## Submit a theme

Open a pull request that adds the theme to the shared [THEMES.md](THEMES.md) catalog, or use the theme-submission issue form to propose an entry. Keep all theme entries in that single file so every README translation uses the same catalog. Include:

- Theme name and a canonical link to its original repository or project page.
- A preview image hosted by the theme's author, or a preview file already included in the source project.
- The author or maintainer's name, when available.
- The license name and a direct link to the source project's license file.

Themes without a clearly stated license are not eligible for inclusion. Do not assume that publicly accessible files are free to redistribute. This catalog links to original projects; do not copy theme files, fonts, icons, or artwork into this repository unless their licenses explicitly permit it.

## Acceptance guidelines

- Most of the interface should be meaningfully customized. A default GRUB menu with only a wallpaper changed is not sufficient.
- A fork or derivative must be recognizably different from its upstream theme and must comply with the upstream license.
- Avoid themes that are substantially similar to entries already in the catalog.
- Anime-inspired themes are welcome, but avoid entries built primarily around generic character renders with little original interface design.
- AI-generated imagery is not accepted.
- Themes and previews must be safe for work.
- Keep existing entries intact unless the pull request specifically corrects an attribution, source URL, preview, or license detail.

## Pull request checklist

Before opening a pull request, verify the source URL, license URL, and preview. Credit the original creator and clearly identify any derivative work. Add, update, or remove theme entries only in [THEMES.md](THEMES.md); do not copy the theme gallery into translated README files.

## Reporting an issue

Use the bug report form for broken links, incorrect details, or other catalog problems. Use the theme submission form to suggest a theme when you cannot prepare a pull request. The repository's Issues feature must be enabled for these forms to appear.
